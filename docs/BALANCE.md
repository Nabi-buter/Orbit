# 밸런스 점검 기록 (3단계)

모든 수치는 `src/config/balance.js`(공통)와 `src/config/weapons.js`(무기별)에서만 조정한다.
전투 **규칙**은 바꾸지 않고 **수치**만 조정했다. 표의 수치는 모두 `[TEMP]` 임시값이다.

## 점검 도구

```bash
node scripts/simulate.js 40 hard     # AI 대 AI: 무기 상성표, 경기 시간, 이벤트 빈도, 궁극기 결과
node scripts/balance-check.js        # 단순 전략 봇(약공/강공 연타, 점프 남발, 가드만) vs AI, 강공 vs 약공 거리별 판정
npm test                             # 규칙·수치 불변식 (콤보 틈, 특수강공 피해 동일, 궁극기 즉시 판정 등)
```

> ⚠ AI 대 AI 결과는 **AI의 플레이 방식에 크게 좌우되는 참고 지표**다. 실제 사람 대전 테스트로 반드시 확인해야 한다.

| 항목 | 변경 | 이유 | 예상 효과 |

| --- | --- | --- |
| 장검 | 약 후딜 12→14, 강 후딜 20→24 | 최대 사거리 강공 남발 억제, 헛친 약공을 반격 가능하게 |

| 단검 | 이동 1.12→1.15, 대시 소모 0.85→0.8, **대시 거리 ×1.2**, 약 피해 34→36·사거리 72→76, 후딜 +1~3 | 사거리 열세로 접근이 어려움 → 파고들기 수단 보강 |

## 4단계: 무기별 콤보 상한과 숨 고르기 (연타 대응)

규칙(`src/core/combo.js`):
- 약공을 누를 때마다 무기의 약공 콤보 순서가 진행된다. 강공도 마찬가지.
- 약공/강공 각각 최대 연속 횟수, 섞었을 때 전체 최대 횟수가 있다.
- 마지막으로 쓴 종류가 상한에 닿거나 전체 상한에 닿으면 콤보 종료 → **숨 고르기**(약/강공격 불가).
  한 종류만 연타했다면 `fullLag`, 약·강을 섞었다면 `mixedLag`(짧음).
- 콤보가 끝난 뒤 `combo.window`(26f) 안에 다시 공격하면 같은 콤보로 이어서 센다
  → "콤보 → 잠깐 빠짐 → 다시 몰아치기"로 상한을 피할 수 없다.
- 숨 고르기 중에도 가드·이동·대시·점프·궁극기·특수강공은 가능. 피격되면 콤보 카운트 초기화.

| 무기 | 약공 콤보 | 강공 콤보 | 섞으면 최대 | 딜레이(단일/혼합) | 이유 |
| --- | --- | --- | --- | --- | --- |
| 장검 | 3 (베기→되베기→찔러 마무리) | 2 (내려베기→올려베기) | 4 | 40 / 18f | 균형형 |
| 대검 | **2** (좌상단 베기→우상단 베기) | 1 | 3 | 46 / 24f | 한 방이 무거운 대신 연속 공격이 가장 짧음 |
| 단검 | **3** (찌르기→가르기→깊게 찌르기) | 2 | 4 | 34 / 16f | 빠르지만 너클보다 짧은 연속 |
| 도끼 | 2 | 2 | 3 | 42 / 22f | 가드 압박이 강해 연속은 짧게 |
| 창 | 3 | 2 | 3 | 40 / 20f | 원거리 견제를 끝없이 이어가지 못하게 |
| 너클 | **5** (잽→잽→훅→바디→어퍼) | 3 | 7 | 32 / 14f | 사거리 불리를 연속 공격으로 보상 |

함께 바꾼 수치: 너클 약공을 한 번에 1타(잽)로 변경(피해 25), 너클 섞으면 최대 6→7, 단검 약공 피해 36→39.

## 6단계: 딜레이 소폭 감소 + 콤보 연결 개선

- tempo 약 13% 하향: 장검 1.45→1.25, 대검 1.55→1.35, 단검 1.3→1.15, 도끼 1.6→1.4, 창 1.4→1.25, 너클 1.3→1.15.
  콤보 종료 딜레이도 같은 비율로 감소, 대시 쿨다운 40→34f, 착지 경직 8→6f, 완벽패링 경직 42→38f.
- **콤보 예약 입력**: 공격 중에 누른 다음 공격은 연결 시점까지 기억했다가 바로 나간다 (한 번만 눌러도 콤보가 이어짐).
- **헛쳐도 콤보 문자열 진행**: 맞히거나 막히면 `cancelFrom`, 헛치면 `cancelFrom + combo.whiffDelay(8f)` 부터 다음 단계.
  콤보 상한과 숨 고르기 규칙은 그대로라 무한 연타는 여전히 불가.

결과(어려움 AI 대 AI): 장검 54 · 대검 45 · 단검 61 · 도끼 48 · 창 47 · 너클 37 (%). 약공 연타 봇 승률 보통 3% / 어려움 0%.

## 7단계: 무기별 6개 변수로 밸런스 조정

### 변수 (`src/config/weapons.js` 의 `KNOBS` 한곳)

| 변수 | 의미 |
| --- | --- |
| combo | 약공/강공 연속 횟수, 섞을 때 최대, 콤보 종료 딜레이 |
| reach | 리치 배율 (판정 폭) |
| damage | 데미지 배율 (약/강/낙하, 특수강공·궁극기 제외) |
| speed | 공격 속도 = 무게감 배율 (클수록 느림) |
| hp *(보조)* | 체력 배율 |
| guardTaken *(보조)* | 상대 공격을 막을 때 내 가드 게이지 감소량 배율 |

콤보 횟수를 바꾸면 단계가 자동으로 늘거나 줄고(중간 동작 반복), 마무리 동작은 항상 마지막에 온다.

### 측정 방법 (`scripts/evalcore.js`, `scripts/matrix.js`)
처음에는 같은 난이도 AI끼리만 붙였더니 상성이 0%/100%로 갈렸다(AI 행동이 기계적이라 몇 프레임 차이로 승패가 통째로 뒤집힘).
그래서 ① AI 반응 속도·공격 성향에 사람 같은 흔들림을 넣고 ② 난이도 9가지 교차(쉬움~어려움 × 양쪽) ③ 시작 거리 무작위로 바꿔
상황을 다양화했다. 무기당 540판 기준 측정 오차는 약 ±2%p.

### 탐색 (`scripts/tune.js`)
1단계: 주 변수 4개(공격속도·데미지·리치·콤보)를 승률 오차에 비례해 하나씩 조정, 무기 정체성 규칙(대검 최고 위력·최저 속도,

## 8단계: 딜레이 체계 재정비 · 공격권 이전 · 연타 너프 · AI 패턴 예측

### AI: 상대 패턴 예측 (`src/ai/predictor.js`)
- 상대 행동을 큰 틀 8가지(약공·강공·가드·접근·후퇴·점프·대기·궁극기)로 분류.
- 거리 구간(근/중/원)별 빈도 + "직전 행동 → 다음 행동" 전이 빈도를 지수 감쇠로 학습 → 다음 행동 확률 예측.
- 성향 요약: 돌격형 / 견제형 / 수비형 / 점프형 / 반격형 / 균형형 (PvE 화면에 "분석: …· 예상: …" 표시).
- 예측별 대응: 강공 → 사거리 밖에서 기다렸다 헛치게 하고 반격(또는 더 빠른 약공으로 선공), 약공 연타 → 미리 가드/뒤로 빠지기/
  사거리로 이기기, 접근 → 길목 견제, 가드 → 가드 압박(강공), 점프 → 대공·착지 반격, 대기 → 미끼 걸음, 궁극기 → 거리 벌리기.
- 벽 인식: 뒤로 빠질 공간이 없으면 상대 머리 위로 점프하거나 가드.
- 반격 시 시간이 충분하면 강공으로 크게 반격. 상대가 견제형이면 느린 강공에 완벽패링을 더 노림.
- 예측 반영 정도는 난이도별 `adapt` (쉬움 0.25 / 보통 0.55 / 어려움 0.8). 모든 관측은 반응 지연이 적용된 정보만 사용.

결과: 약공 연타 봇 승률 — 어려움 AI 상대 3%, 보통 25%.

## 9단계: 강공 콤보

- 모든 무기에 2단 이상의 강공 콤보, **강공 콤보 수 < 약공 콤보 수** (강공은 느리고 강한 기술). 테스트·자동 탐색 모두 이 규칙을 강제.

| 무기 | 약공 콤보 | 강공 콤보 |
| --- | --- | --- |
| 장검 | 베기 → 되베기 → 찔러 마무리 | 내려베기 → 올려베기 |
| 대검 | 좌상단 베기 → **횡베기** → 우상단 베기 (2→3) | 대검 내려찍기 → **대검 올려베기** (1→2) |
| 단검 | 찌르기 → 가르기 → 깊게 찌르기 | 이연 찌르기 → 돌려 베기 |
| 도끼 | 내려찍기 → **올려치기** → 옆치기 (2→3) | 도끼 찍기 → 휘둘러 찍기 |
| 창 | 찌르기 → 재찌르기 → 밀어 찌르기 | 휘두르기 → 회전 베기 |
| 너클 | 잽 → 잽 → 훅 → 바디 블로 → 어퍼컷 | 돌진 연타 → 러시 → 스트레이트 |

- 강공도 약공처럼 연타로 이어진다. 헛쳤을 때 이어지는 시점은 약공 `cancelFrom + 12f`, 강공 `cancelFrom + 20f` (더 늦음).
- 대검은 콤보가 늘어난 만큼 데미지 0.89→0.87, 리치 0.96→0.95, 속도 1.41→1.43. 너클 소폭 상향.
- 결과(새 시드): 장검 54 · 대검 48 · 단검 52 · 도끼 49 · 창 49 · 너클 48 (%).

## 10단계: 모티브(로블록스 Dueling Grounds) 반영

### 조사한 내용 (공개 가이드·위키 요약, 정확한 공격 시간은 공개 자료 없음)
- 조작: 약공(M1)·강공(M2), 패링은 짧게(F), 막기는 길게, 회피, 궁극기.
- 패링: 연속으로 시도할수록 판정이 14 → 10 → 8프레임으로 짧아지고, 실패 후 경직이 6 → 12 → 18프레임으로 길어진다(60fps).
- 막기는 자세 게이지를 깎고, 패링 성공은 상대 자세를 깎는다. 자세가 무너지면 피니셔.
- 기본 콤보는 약 ×3 → 강(마무리). 강공은 느리지만 막기를 강하게 압박한다.
- 무기 성격: 카타나(균형) / 단검(빠름·다타) / 건틀릿(연타·압박) / 나기나타(긴 리치·고위력·느림) / 워해머(무거움).

### 적용한 규칙
| 항목 | 내용 |
| --- | --- |
| 패링 단계 | `guard.parry`: 판정 [14, 10, 8]f, 헛패링 경직 [6, 12, 18]f, 60f 안에 다시 누르면 단계 상승. 성공하면 초기화. 버튼을 계속 누르면 패널티 없이 막기로 전환 |
| 패링 → 자세 | 완벽패링 성공 시 공격자 가드(자세) 게이지 −18. 0이면 가드 브레이크 → 특수강공(피니셔) |
| 공격 리듬 | `timing: { windup: 1.45, recovery: 0.8 }` — 모든 공격의 예비 동작은 길게(읽히게), 후딜은 짧게 |
| 콤보 | 기본 약 → 약 → 약 → 강 (장검 최대 4). 공격권 이전 규칙은 그대로 |

기존에 합의한 규칙(일반 막기 피해 50%, 대시 무적 없음)은 유지했다. 모티브는 회피에 무적 프레임이 있고 막기 피해가 0이라는 자료도 있으나, 바꾸려면 따로 결정이 필요하다.

## 11단계: 콤보 중간 역공 차단 · AI 대시 · 캐릭터 교체

### 콤보가 끊기던 원인
1. **경직 기준점**: 피격 경직이 "닿은 프레임"부터 셌다. 판정이 길수록(대검 4프레임) 일찍 닿으면 피격자가 그만큼 일찍 풀려
   연결 공격보다 단검 약공(7f)이 먼저 들어갔다. → 경직(피격·가드 모두)을 **판정이 끝나는 프레임 기준**으로 센다
   (`combat.js` `late`). 어디서 닿든 콤보 틈이 같다.
2. **연결 단계마다 다른 예비 동작**: 장검 2타(되베기)는 1타보다 2프레임 늦게 나가 틈이 그만큼 벌어졌다.
   → 약공 연결 단계의 예비 동작을 첫 타와 같게 맞추고 차이는 후딜로 옮겼다.
3. `combo.minGap` 4 → 3. 콤보 사이 틈은 여전히 ≥2프레임이라 **가드·패링은 가능**, 약공 역공은 불가.

테스트: `tests/combo.test.js` "콤보 중간에 피격자가 약공으로 역공해도 연결 공격이 먼저 들어간다", "콤보 사이 틈에서 가드는 가능하다".

### 대시
- 대시 쿨타임 34 → **60프레임(1초)**.
- AI 앞 대시(파고들기) 제한: 개시 후 2초간 금지, 한 번 쓰면 2.5~4초간 걸어서 간격을 잰다 (`ai.js` `AI_DASH_IN`).

- 공략 루틴이 판단마다 가드를 풀어 미리 잡아 둔 완벽패링이 취소되던 버그 수정.
- 헛치게 한 뒤 대시로 들어가는 반격이 상대 판정 중에 도착하던 문제: 도착 시점이 판정 종료 뒤가 되도록 지연.
- 콤보 중 강공 연결이 큰 틈을 만들어 상대 공격이 먼저 들어가던 문제: 상대가 가장 빨리 낼 수 있는 공격보다 먼저 닿을 때만 강공으로 연결.

## 19단계: 관절 리그 — 실제로 무기를 쥐고 휘두르는 모션 (렌더 전용, 판정 무관)

## 23단계: 무기 판정 = 무기 그림

문제: 판정이 무기 그림과 따로 정한 사각형이라, 그려진 무기가 상대에게 닿아도 피해가 없는 일이 잦았다
(예전 판정 사거리: 장검 약공 96 · 대검 약공 115 · 단검 79 · 창 141 — 그려진 무기는 128~191).

해결 (`src/render/hitGeometry.js`):
- 약공·강공 판정을 그리기와 똑같은 계산(모션 → 손 위치 IK → 무기 각도 · 무기 그림 길이)으로 만든 **무기 선분**으로.
  칼날 · 도끼 자루+수염형 날 · 창 자루+잎날 · 너클 주먹. 프레임 사이 2개 보간으로 빠른 휘두름도 건너뛰지 않음.
- 무기를 만들 때 한 번 계산해 정수로 저장 → 시뮬레이션은 선분-사각형 판정(사칙연산)만 → 온라인 동기화 안전.
- 사거리는 이제 무기 그림·모션이 정한다(리치 배율은 근접 공격에 쓰지 않음).
- 올려베기류 준비 자세에서 칼날이 상대 몸에 걸쳐 보이던 것, 따라가기에서 손이 판정보다 멀리 나가던 것 정리.
- 검사 `node scripts/hit-visual-check.js`: 휘두르는 무기가 상대 몸에 닿는데 피해 없음 **0/478**
  (남은 16건은 바짝 붙은 거리에서 긴 무기를 낮게 든 경우·너클 연타 사이).
- 확인: F2 판정 표시와 `tools/strip.html` 이 무기 선분을 그대로 그린다.

재조정 (사거리가 그림대로 늘어 단검 73% · 대검·도끼 40%):
단검 데미지 1.1→0.9 · 체력 1.07→1.0, 대검 데미지 0.9→0.94 · 체력 1.0→1.08 · 공격시간 1.26→1.3,

새 시드 21 / 33: 편차 4.5 / 3.0%p, 최대 상성 66~67%.

## 남은 과제

- 공격이 빨라진 단검·너클 상대로 약공 연타 봇이 다시 AI를 이긴다(보통 53%, 어려움 31%). AI 의 리듬 패링이 새 패링 단계 규칙(연속 시도 시 판정 감소)과 잘 맞지 않는 영향이 있다.

- "사거리에 들어오는 그 프레임에 강공"을 내는 기계적 견제 봇은 여전히 AI를 이긴다(어려움 86%). AI가 타수는 더 많지만 강공 한 방 피해 차이로 진다.
  사람이 프레임 단위로 재현하기 어려운 전략이지만, AI의 거리 싸움(사거리 경계 유지·헛치기 유도)을 더 다듬을 여지가 있다.

- 너클이 AI 대전에서 여전히 약하다. AI가 너클의 장점(초근접 연타)을 살리지 못하는 영향도 크므로 사람 테스트 후 판단.
- 단순 연타 봇이 AI를 이긴다 → AI가 반격/거리 조절을 더 잘하도록 개선 필요(밸런스 수치보다는 AI 문제).
- 무기별 고유 궁극기 설계(현재는 공통 임시 타입).
